# Store and Marketing Asset Production

## Source of truth

- Inspect the shipped app and current brand system before writing copy or composing visuals.
- Capture real UI from the release candidate using deterministic, privacy-safe sample accounts/data and reproducible navigation. Remove personal information, debug chrome, unstable timestamps, and accidental status/notification content.
- Build a narrative from primary value to proof and breadth. The first visible frames must communicate the strongest audience promise and remain legible at store/search size.
- Separate raw captures from derived marketing compositions. Preserve source paths, device/OS, locale, app version/build, data fixture, capture command/manual steps, and output mapping.

## Reproducible production

Prefer a deterministic pipeline that composes brand background, device framing, localized headline/subtitle, and real capture without altering product truth. Validate current official dimensions, orientation, safe areas, alpha/color mode, file size/type, ordering, device-family recognition, video duration/audio, and per-locale requirements immediately before upload.

Generated imagery may support decorative backgrounds or non-product campaign art when policy permits and provenance is recorded. It must never create fake UI, fake output, testimonials, rankings, medical/financial outcomes, unavailable features, or misleading before/after states.

## Metadata and localization

Create a per-platform/storefront matrix for name, subtitle/short description, description, promotional text, release notes, keywords/tags/category, URLs, privacy/support contact, copyright, review notes, demo access, pricing/products, and required declarations. Respect current field limits and policies. Localize meaning and search intent rather than mechanically translating; obtain native review for priority markets.

Run product, legal/privacy, brand, accessibility/readability, localization, and claim reviews. Record upload/dry-run evidence and distinguish generated files from console-only completion.
