# Changelog

## 2.10.0 — 2026-07-20

- Added auditable human GO/NO-GO overrides for discovery, artifact review, and release-planning gates without allowing overrides to fabricate implementation, launch, or metric evidence.
- Kept `single-mobile-indie` as the sole product-discovery profile while adding problem framing, evidence modes, assumptions, proportional concept/usability validation, and a structured promotion brief.
- Fixed canonical suffix `(P)` parsing and strengthened conventional claims, passed-evidence completion, deterministic artifact revision/invalidation, derived lifecycle status, orphan-lock recovery, and Codex adapter checks.
- Bound new release contracts to structured candidate/scope digests, expanded paid-media authorization, and added schemas for metric snapshots, experiments, and routed growth learning.
- Added context manifests, delta-first guidance, research freshness, bounded correction loops, token budgets/telemetry, applicability modules, and a pending final-validator capability that is derived from the selected validation profile.
